## `bonya fs`

Reads and writes files inside a sandbox. Every subcommand names its sandbox by name or id, interchangeably, and omitting it opens a picker:

```shell
bonya fs ls web /root
bonya fs ls /root        # prompts for the sandbox
```

A fresh sandbox runs as `root` with `HOME=/root`. There is no `/workspace` directory; use `/root` or `/tmp`, or `mkdir` what you need.

| Subcommand | Usage | Description |
| --- | --- | --- |
| `read` (`cat`) | `bonya fs read [sandbox] <path>` | Print a remote file to stdout. |
| `write` | `bonya fs write [sandbox] <path> <local-file-or->` | Write a local file (or stdin with `-`) to a remote path. |
| `upload` | `bonya fs upload [sandbox] <local> <remote>` | Upload a local file. |
| `download` | `bonya fs download [sandbox] <remote> <local>` | Download a remote file. |
| `ls` | `bonya fs ls [sandbox] <path>` | List a directory. |
| `stat` | `bonya fs stat [sandbox] <path>` | Show metadata about a path. |
| `mkdir` | `bonya fs mkdir [sandbox] <path>` | Create a directory. |
| `rm` | `bonya fs rm [sandbox] <path> [--recursive]` | Remove a file or directory. |
| `mv` | `bonya fs mv [sandbox] <from> <to>` | Move or rename. |

```console
$ bonya fs write docs-probe /tmp/a.txt ./local.txt
Wrote 3B to /tmp/a.txt

$ bonya fs read docs-probe /tmp/a.txt
hi

$ bonya fs stat docs-probe /tmp/a.txt
PATH      /tmp/a.txt
NAME      a.txt
KIND      file
SIZE      3B
MODE      0644
MODIFIED  2026-11-10 00:56

$ bonya fs ls docs-probe /tmp
NAME   KIND  SIZE  MODE  MODIFIED
a.txt  file  3B    0644  2026-11-10 00:56
```

`ls` marks directories with a trailing `/` and shows symlinks with the kind `symlink`. A missing path fails with `not found`.
