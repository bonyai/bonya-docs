This page covers the **Account** commands that aren't organization-related. See [`bonya org`](/cli-reference/org) for switching organizations and [`bonya login`](/cli-reference/login) for authenticating.

## `bonya whoami`

Shows where the API key, endpoint, and organization id currently in effect each come from.

```shell
bonya whoami
```

```console
$ bonya whoami
api key:         environment variable
endpoint:        (default): https://api.bonya.ai
organization id: (personal — not set)
```

<Note>
`whoami` makes **no network call**. It only reports which source — `--flag`, `environment variable`, `bonya login (saved)`, or `(not set)` — each setting resolves from, following the same [precedence order](/cli-reference/configuration#precedence) every other command uses. It never confirms the key is actually valid; use `bonya list` or another real command for that.
</Note>

The API key's value is never printed, even when it's set — only its source. Endpoint and organization id print their actual saved value alongside the source, since those aren't secret.

## `bonya logout`

Removes the API key (and endpoint/organization id) saved by `bonya login`, by deleting the config file.

```shell
bonya logout
```

```console
$ bonya logout
Removed /Users/you/.config/bonya/config.json
```

This only affects the saved login — a `--api-key` flag or `BONYA_API_KEY` environment variable still works after `logout`, since those take priority over (and don't depend on) the saved config.

## `bonya version`

<Info>Alias: `v`</Info>

Prints the installed CLI version.

```shell
bonya version
```

```console
$ bonya version
bonya version v1.4.0
```

`bonya --version` prints the same string, and the version is also folded into `bonya --help`'s output next to the `-h` flag. Note that `-v` is short only for the `version` subcommand (`bonya v`) — the root `--version` flag itself has no single-letter shorthand.
