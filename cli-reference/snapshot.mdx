## `bonya snapshot`

<Info>Alias: `snap`</Info>

A snapshot captures a sandbox's files. Restore one into a new sandbox with [`bonya create --snapshot`](/cli-reference/create). See [Snapshots](/concepts/snapshots).

## `create`

```shell
bonya snapshot create [sandbox] [--name NAME]
```

| Flag | Description |
| --- | --- |
| `--name` | Snapshot name, at most 128 bytes. Defaults to the sandbox name plus the UTC time. |
| `--idempotency-key` | Idempotency key for the create request. |

```console
$ bonya snapshot create docs-probe --name base
ID       snp-lq26mnn67u0egu
NAME     base
SOURCE   sb-iwmjfuuyixl300
STATE    published
FILES    10.0GB
CREATED  2026-11-10 00:56
```

## `list`

<Info>Alias: `ls`</Info>

```console
$ bonya snapshot list docs-probe
ID                  NAME  STATE      FILES   CREATED
snp-lq26mnn67u0egu  base  published  10.0GB  2026-11-10 00:56
```

## `delete`

<Info>Alias: `rm`</Info>

```shell
bonya snapshot delete [sandbox] <snapshot-id>
```
