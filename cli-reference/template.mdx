## `bonya template`

<Info>Aliases: `templates`, `tpl`</Info>

### `list`

<Info>Aliases: `ls`, `l`</Info>

Lists your organization's saved templates.

```console
$ bonya template list
TEMPLATE  NAME      REVISION  IMAGE      DESCRIPTION
tpl-...   node-dev  2         node:22
```

With none yet it prints `No templates yet.` The CLI only lists templates. To create or edit them use the [SDKs](/sdks/typescript/usage#templates) or the [REST API](/api-reference), then use one with `bonya job run --template`.
