## `bonya preview`

<Info>Alias: `pv`</Info>

A preview publishes a port inside a sandbox at an HTTPS URL. See [Previews](/concepts/previews).

## `create`

```shell
bonya preview create [sandbox] <port> [--auth private|public] [--grant-ttl 8h]
```

| Flag | Default | Description |
| --- | --- | --- |
| `--auth` | `private` | `private` requires a grant token; `public` lets anyone with the URL in. |
| `--grant-ttl` | service default | How long your browser may open a private preview. |

Ports must be 1024–65535.

```console
$ bonya preview create docs-probe 3000
ID          pv-7bqqhlip54hrli6pgtrbdgz4xi
URL         https://pv-7bqqhlip54hrli6pgtrbdgz4xi.tv.bonya.ai
PORT        3000
AUTH        private
OPEN        https://pv-7bqqhlip54hrli6pgtrbdgz4xi.tv.bonya.ai/?bonya_token=bpv_...
GRANT ENDS  2026-11-10 01:56

Open the OPEN URL once in your browser; it is shown only now and works for whoever has it.
```

The `OPEN` URL carries a one-time grant token. It is shown only at creation.

## `list`

```console
$ bonya preview list docs-probe
ID                             URL                                                PORT  AUTH
pv-7bqqhlip54hrli6pgtrbdgz4xi  https://pv-7bqqhlip54hrli6pgtrbdgz4xi.tv.bonya.ai  3000  private
```

## `delete`

```shell
bonya preview delete [sandbox] <preview-id>
```
