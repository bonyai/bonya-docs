---
title: Quickstart
description: Create a sandbox and run a command in under 5 minutes
---

This walks through the smallest possible loop: get a key, create a sandbox, run a command in it, clean up. A sandbox boots in about a second from the deployment's default image.

<Steps>
  <Step title="Get an API key">
    Install the CLI and log in — this opens a browser tab for you to approve, then hands the CLI a `byk_`-prefixed personal API key.

    <CodeGroup>
    ```shell Homebrew
    brew install bonyai/tap/bonya
    bonya login
    ```

    ```shell Install script
    curl -fsSL https://get.bonya.ai/install.sh | sh
    bonya login
    ```
    </CodeGroup>

    See [Authentication](/authentication) for exactly what `bonya login` does under the hood, and how to mint a key without it. Once you have a key, export it — the CLI and every SDK read this variable by default:

    ```bash
    export BONYA_API_KEY=byk_...
    ```
  </Step>
  <Step title="Install an SDK (optional)">
    Skip this if you're only using the CLI or raw REST.

    <CodeGroup>
    ```bash TypeScript
    npm install @bonya-ai/bonya
    ```

    ```bash Python
    python -m pip install bonya
    ```

    ```bash Go
    go get github.com/bonyai/bonya-sdk-go
    ```
    </CodeGroup>
  </Step>
  <Step title="Create a sandbox">
    `POST /v1/sandbox` returns `202` immediately by default, with the sandbox still `creating`. Pass `?wait=ready` to block until it is running and get `201` back instead. An empty body uses the default image; you can also pass `image`, `snapshot`, `template_id`, `name`, `network`, `env` and more.

    <CodeGroup>
    ```shell cURL
    curl -s -X POST "https://api.bonya.ai/v1/sandbox?wait=ready" \
      -H "Authorization: Bearer $BONYA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"name": "scratch"}'
    ```

    ```shell CLI
    bonya create scratch
    ```

    ```ts TypeScript
    import { Bonya } from "@bonya-ai/bonya";

    const client = new Bonya();
    const sandbox = await client.createSandbox({ name: "scratch" });
    console.log(sandbox.id);
    ```

    ```python Python
    from bonya import Bonya

    with Bonya() as client:
        sandbox = client.create_sandbox(name="scratch")
        print(sandbox.id)
    ```

    ```go Go
    client, err := bonya.NewClient()
    if err != nil {
        log.Fatal(err)
    }

    ctx := context.Background()
    sandbox, err := client.Create(ctx, bonya.CreateOptions{Name: "scratch"})
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(sandbox.ID)
    ```
    </CodeGroup>

    The response is the sandbox itself: `{ "id": "sb-...", "name": "scratch", "state": "running", "vcpus": 1, "memory_mib": 1024, ... }`. See [Sandboxes](/concepts/sandboxes) for the full lifecycle.
  </Step>
  <Step title="Run a command">
    The simplest way to run something is buffered exec — one JSON request, one JSON response, no WebSocket involved. A non-zero exit code is still a `200`; check `exit_code` in the body, which looks like `{"stdout": "hello from bonya\n", "stderr": "", "exit_code": 0, "took_ms": 60.7}`.

    <CodeGroup>
    ```shell cURL
    curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/exec" \
      -H "Authorization: Bearer $BONYA_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"command": ["echo", "hello from bonya"]}'
    ```

    ```shell CLI
    bonya exec $SANDBOX_ID -- echo "hello from bonya"
    ```

    ```ts TypeScript
    const result = await sandbox.exec(["echo", "hello from bonya"]);
    console.log(result.stdout, result.exitCode);
    ```

    ```python Python
    result = sandbox.exec(["echo", "hello from bonya"])
    print(result.stdout, result.exit_code)
    ```

    ```go Go
    result, err := sandbox.Exec(ctx, "echo", "hello from bonya")
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(result.Stdout, result.ExitCode)
    ```
    </CodeGroup>

    That's one of three ways to run a command — see [Run a command](/guides/run-a-command) for the WebSocket TTY and managed-session modes, which are what you want for interactive shells or long-running processes.
  </Step>
  <Step title="Clean up">
    Deletion returns the sandbox with `state: "deleted"`.

    <CodeGroup>
    ```shell cURL
    curl -s -X DELETE "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID" \
      -H "Authorization: Bearer $BONYA_API_KEY"
    ```

    ```shell CLI
    bonya delete $SANDBOX_ID
    ```

    ```ts TypeScript
    await sandbox.delete();
    ```

    ```python Python
    sandbox.delete()
    ```

    ```go Go
    sandbox.Delete(ctx)
    ```
    </CodeGroup>
  </Step>
</Steps>
