`@bonya-ai/bonya-mcp` is a [Model Context Protocol](https://modelcontextprotocol.io) server for the Bonya Compute REST API. It lets any MCP client — Claude Desktop, Claude Code, Cursor, and others — create and manage **sandboxes**, run commands, work with files, manage long-lived background **sessions**, create **preview** URLs, and run one-off or scheduled **jobs**, all through tool calls instead of raw HTTP.

<Note>
The server is self-contained: it talks to the Bonya Compute REST API directly and does not depend on the `@bonya-ai/bonya` or `bonya` SDKs. It covers the same public API as the [API reference](/api-reference).
</Note>

## Tool groups

The server registers 63 tools across these groups:

  <Card title="Sessions" icon="layer-group">

  <Card title="Previews" icon="link">

  <Card title="Jobs & schedules" icon="list-check">

## What's out of scope

- **Interactive/streaming endpoints**: the API's WebSocket surfaces (TTY `exec`, session `attach`) don't fit a request/response MCP tool call. `sandbox_exec` covers non-interactive buffered commands, and `session_create` covers long-running background processes.
- **Identity management**: creating organizations, members, invites and API keys isn't available to API keys.
- **Billing and usage**: not part of the public API.
