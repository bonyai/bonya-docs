---
title: Build, run, and preview a web app
description: Get a small web page served from a sandbox and reachable at a preview URL, entirely from the CLI
---

Serve a small web page from a sandbox and open it in your browser, entirely from the `bonya` CLI. If you haven't installed the CLI or logged in yet, start with the [Quickstart](/quickstart).

<Steps>
  <Step title="Create a sandbox">
    ```shell
    bonya create web
    ```

    ```console
    ID       sb-sp9h1z6hn250e6
    NAME     web
    STATUS   running
    SOURCE   bonya-dev-x86_64-xeon8358-1c1024m-v1
    SIZE     1 vCPU, 1024 MiB
    CREATED  2026-11-10 01:06
    ```
  </Step>

  <Step title="Write the page">
    `fs write` takes a local file, or `-` to read stdin. A sandbox starts in `/` as `root`, so make a directory under `/root`:

    ```shell
    bonya exec web -- mkdir -p /root/site
    echo '<h1>Hello from Bonya</h1>' | bonya fs write web /root/site/index.html -
    bonya fs ls web /root/site
    ```

    ```console
    Wrote 26B to /root/site/index.html
    NAME        KIND  SIZE  MODE  MODIFIED
    index.html  file  26B   0644  2026-11-10 01:06
    ```

    To ship a whole project, tar it locally, `bonya fs upload` the archive, and extract it with `bonya exec web -- tar xzf ...`. `fs upload` moves one file per call.
  </Step>

  <Step title="Start a server in a managed session">
    Run the server in a [session](/concepts/sessions) so it keeps running after you disconnect. Python is preinstalled:

    ```shell
    bonya session create web site -- python3 -m http.server 3000 --directory /root/site
    ```

    ```console
    NAME         site
    STATUS       idle
    COMMAND      python3 -m http.server 3000 --directory /root/site
    WORKING DIR
    ```
  </Step>

  <Step title="Publish a preview URL">
    ```shell
    bonya preview create web 3000
    ```

    ```console
    ID          pv-yusal3rogx6y3g2k6u5k4hlntq
    URL         https://pv-yusal3rogx6y3g2k6u5k4hlntq.tv.bonya.ai
    PORT        3000
    AUTH        private
    OPEN        https://pv-yusal3rogx6y3g2k6u5k4hlntq.tv.bonya.ai/?bonya_token=bpv_...
    GRANT ENDS  2026-11-10 02:06

    Open the OPEN URL once in your browser; it is shown only now and works for whoever has it.
    ```

    The preview is **private** by default. Open the `OPEN` URL once; the gateway trades the token for a cookie and redirects to the clean URL. To publish without a credential, use `--auth public`. See [Previews](/concepts/previews).
  </Step>

  <Step title="Clean up">
    ```shell
    bonya preview delete web pv-yusal3rogx6y3g2k6u5k4hlntq
    bonya delete web --force
    ```
  </Step>
</Steps>
