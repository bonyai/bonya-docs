---
title: Run a one-off script
description: Run a script on a throwaway sandbox as a job and look the result up later
---

A [job](/concepts/jobs) runs a command or script, tracks it to completion, and can create (and delete) a sandbox just for the run.

<Steps>
  <Step title="Write the script locally">
    ```shell
    cat > hello.sh <<'EOF2'
    #!/bin/sh
    echo "hello from $(hostname)"
    uname -sr
    EOF2
    ```
  </Step>

  <Step title="Run it as a job">
    `--new` creates a fresh sandbox for the run and deletes it afterwards. `--wait` blocks for the result, prints the output, and exits with the script's exit code.

    ```shell
    bonya job run --new --script ./hello.sh --wait
    ```

    ```console
    hello from sb-klk91oc6m8rsa8
    Linux 4.19.0-gvisor
    ```

    Add `--keep` to keep the sandbox, `--timeout 10m` to bound the command, or `--env KEY=VALUE` to pass variables.
  </Step>

  <Step title="Look up the run later">
    Without `--wait`, `job run` prints the run id and returns immediately. List and inspect runs any time:

    ```shell
    bonya job list --limit 1
    ```

    ```console
    RUN                 NAME  STATUS     SANDBOX            STARTED
    run-mr8t6t3scvqdvq        completed  sb-klk91oc6m8rsa8  2026-11-10 01:05
    ```

    ```shell
    bonya job get run-mr8t6t3scvqdvq
    ```

    ```console
    RUN        run-mr8t6t3scvqdvq
    NAME
    STATUS     completed
    SANDBOX    sb-klk91oc6m8rsa8
    STARTED    2026-11-10 01:05
    FINISHED   2026-11-10 01:05
    EXIT CODE  0

    stdout
    hello from sb-klk91oc6m8rsa8
    Linux 4.19.0-gvisor
    ```
  </Step>

  <Step title="Run it on a schedule">
    ```shell
    bonya schedule create --new --every 1h --script ./hello.sh
    ```

    See [`bonya schedule`](/cli-reference/schedule).
  </Step>
</Steps>
