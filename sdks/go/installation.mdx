The Go SDK's module path is `github.com/bonyai/bonya-sdk-go`, package name `bonya`. It talks to the Bonya REST API over HTTPS, and to the sandbox edge over a WebSocket for streaming exec and terminal sessions.

## Requirements

- Go 1.24 or newer
- Depends on `github.com/gorilla/websocket`
- A Bonya API key (`byk_...`)

## Install

```bash
go get github.com/bonyai/bonya-sdk-go
```

## Configure

Every option has an environment-variable fallback, so the common case needs no options at all:

<CodeGroup>
```bash Environment variable
export BONYA_API_KEY=byk_...
```

```go Explicit
client, err := bonya.NewClient(
	bonya.WithAPIKey("byk_..."),
	bonya.WithOrganizationID("org_123"),
)
```
</CodeGroup>

| Option | Environment variable | Default |
|---|---|---|
| `WithAPIKey` | `BONYA_API_KEY` | *required* |
| `WithEndpoint` | `BONYA_ENDPOINT` | `https://api.bonya.ai` |
| `WithEdgeEndpoint` | `BONYA_EDGE_ENDPOINT` | the API endpoint |
| `WithOrganizationID` | `BONYA_ORGANIZATION_ID` | your personal organization |
| `WithCABundle` | `BONYA_CA_BUNDLE` | system trust store |
| `WithTimeout` | — | 30 seconds |
| `WithMaxRetries` | — | `2` |
| `WithHTTPClient` | — | a default `http.Client` |

Plain `http` endpoints are accepted only for loopback hosts. An empty organization id is an error, not a silent fallback to your personal organization.

`WithMaxRetries` controls retries of transient failures. Mutations carry an `Idempotency-Key`, which the SDK keeps across its own retries, so a retried call joins the original instead of repeating it.

A `Client` is safe for concurrent use. Create one and reuse it.

## Quickstart

```go
package main

import (
	"context"
	"fmt"
	"log"

	bonya "github.com/bonyai/bonya-sdk-go"
)

func main() {
	ctx := context.Background()

	client, err := bonya.NewClient() // reads BONYA_API_KEY
	if err != nil {
		log.Fatal(err)
	}

	sandbox, err := client.Create(ctx, bonya.CreateOptions{})
	if err != nil {
		log.Fatal(err)
	}
	defer sandbox.Delete(ctx)

	result, err := sandbox.Exec(ctx, "echo", "hello")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Print(result.Stdout) // hello
}
```

That is a real VM: it boots in about a second, runs anything Linux runs, and is gone when `Delete` returns.
