Every call takes a `context.Context` first and returns an `*Error` on failure (see [Errors](#errors)).

## What you can do

| I want to… | Call |
|---|---|
| Start a sandbox | `client.Create(ctx, bonya.CreateOptions{...})` |
| Reconnect to one | `client.Get(ctx, id)` / `client.Sandbox(id)` |
| Find my sandboxes | `client.List(ctx, opts)` / `client.ListAll(ctx, opts)` |
| Run a command | `sandbox.Exec(ctx, "ls", "-la")` / `sandbox.ExecWithOptions(ctx, opts)` |
| Stream output live | `sandbox.ExecStream(ctx, opts)` |
| Keep a process running after I disconnect | `sandbox.CreateSession(ctx, opts)` / `sandbox.AttachSession(ctx, name, opts)` |
| Move files in and out | `ReadFile` / `WriteFile` / `Upload` / `Download` / `ListDir` / `Stat` / `Mkdir` / `Remove` / `RemoveAll` / `Rename` |
| Expose a port to the web | `sandbox.CreatePreview(ctx, port, opts)` |
| Capture disk state | `sandbox.CreateSnapshot(ctx, opts)` / `sandbox.ListSnapshots(ctx)` |
| Clone a running sandbox | `sandbox.Fork(ctx, bonya.ForkOptions{Count: 2})` |
| Pause or keep awake | `sandbox.Pause(ctx, bonya.PauseWarm)` / `sandbox.Keepalive(ctx, d)` |
| Run a managed or scheduled job | `client.RunJob(ctx, spec)` / `client.CreateJobSchedule(ctx, spec)` |
| See templates | `client.ListTemplates(ctx)` |
| Switch organization | `client.ListOrganizations(ctx)` / `bonya.WithOrganizationID(id)` |

## Create sandboxes

```go
sandbox, err := client.Create(ctx, bonya.CreateOptions{
	Name:           "scratch",
	Image:          "python:3.12", // optional: a public OCI image
	IdempotencyKey: "create-job-123",
})
```

| Field | Description |
|---|---|
| `Name` | Display name. Empty generates one. |
| `Image` | A public container image reference (tag or digest). Cannot be combined with `Snapshot`. |
| `Snapshot` | Restore from a snapshot id. The new sandbox boots the snapshot's files with fresh processes. |
| `IdempotencyKey` | Makes the create safe to repeat. Generated and reused across retries if empty. |

`Create` returns once the sandbox is running. A sandbox that failed to start comes back as an `ErrUnavailable` error; retry with a new key.

## Get, list, refresh, delete

```go
sandbox, err := client.Get(ctx, "sb-abc123")

for sb, err := range client.ListAll(ctx, bonya.ListOptions{States: []bonya.State{bonya.StateRunning, bonya.StateWarm}}) {
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(sb.ID, sb.State)
}

_ = sandbox.Refresh(ctx)
_ = sandbox.Delete(ctx)
```

`sandbox.State` is one of `creating`, `running`, `cooling`, `warm`, `cold`, `waking`, `failed`, `deleting`, `deleted` or `lost`.

## Run commands

```go
result, err := sandbox.ExecWithOptions(ctx, bonya.ExecOptions{
	Command:    []string{"bash", "-lc", "uname -a"},
	WorkingDir: "/root",
	Env:        map[string]string{"FOO": "bar"},
	Timeout:    30 * time.Second,
})
fmt.Println(result.ExitCode, result.Stdout, result.Stderr)
```

Without a stream, a zero `Timeout` means the service default of 60 seconds, capped at 10 minutes. Output is capped at 4 MiB per stream, with `StdoutTruncated` and `StderrTruncated` reporting overflow.

### Streaming exec

```go
stream, err := sandbox.ExecStream(ctx, bonya.ExecOptions{
	Command: []string{"bash", "-lc", "echo out; echo err >&2"},
	Stdout:  os.Stdout,
	Stderr:  os.Stderr,
})
if err != nil {
	log.Fatal(err)
}
defer stream.Close()

status, err := stream.Wait()
fmt.Println("exit:", status.ExitCode)
```

Write stdin with `stream.Write`, close it with `stream.CloseStdin()`, and stop the command with `stream.Cancel()`. Set `TTY: true` with `Cols` and `Rows` to run in a terminal. On a stream, `Timeout` stops the command in the sandbox even if your connection breaks (`ExitStatus.TimedOut`).

Each run has an `IdempotencyKey`. Running again with the same key attaches to the first process instead of starting another, which is how you recover after an `ErrOutcomeUnknown`. `AttachOnly` watches or cancels a run whose stream broke.

The process dies when the stream closes. For anything that must outlive your connection, use a session.

## Persistent sessions

```go
_, err := sandbox.CreateSession(ctx, bonya.SessionOptions{
	Name:    "server",
	Command: []string{"bash"},
	Cols:    120,
	Rows:    40,
})

att, err := sandbox.AttachSession(ctx, "server", bonya.AttachOptions{Output: os.Stdout})
att.Write([]byte("npm run dev\n"))
// ... later
att.Detach() // the process keeps running

sessions, _ := sandbox.ListSessions(ctx)
_, _ = sandbox.KillSession(ctx, "server", bonya.KillSessionOptions{})
```

Session names match `^[a-z][a-z0-9-]{0,31}$`. A session keeps running after you detach and replays recent output on attach (`Attachment.ReplayedBytes`, `HistoryDropped`). The attachment reconnects by itself after a pause or a lost connection unless `NoReconnect` is set. `Wait()` returns an `AttachResult` with `Exit`, `Detached` and `TakenOver`.

## Files

```go
_, err := sandbox.WriteFile(ctx, "/root/hello.txt", []byte("hello\n"))
data, err := sandbox.ReadFile(ctx, "/root/hello.txt", 0)

err = sandbox.Mkdir(ctx, "/root/out")
err = sandbox.Rename(ctx, "/root/hello.txt", "/root/out/hello.txt")

entries, err := sandbox.ListDir(ctx, "/root/out")
info, err := sandbox.Stat(ctx, "/root/out/hello.txt")

_, err = sandbox.Upload(ctx, "./local.json", "/root/out/local.json")
_, err = sandbox.Download(ctx, "/root/out/local.json", "./copy.json")
err = sandbox.RemoveAll(ctx, "/root/out")
```

`OpenFile` returns an `io.ReadCloser` and `WriteFileFrom` takes an `io.Reader` for large files.

## Previews

```go
preview, err := sandbox.CreatePreview(ctx, 3000, bonya.PreviewOptions{})
fmt.Println(preview.URL)

// A private preview is opened with a one-time grant token.
fmt.Println(preview.Grant.ExchangeURL)

public, err := sandbox.CreatePreview(ctx, 8080, bonya.PreviewOptions{Auth: bonya.PreviewPublic})

grant, err := preview.CreateGrant(ctx, 10*time.Minute)
grants, err := preview.ListGrants(ctx)
err = preview.Delete(ctx)
```

Ports must be 1024–65535. `Auth` defaults to private, and public is only ever explicit. `Token` and `ExchangeURL` are set only on the grant as it was created; treat them as secrets.

## Lifecycle, snapshots, and forks

```go
err = sandbox.Pause(ctx, bonya.PauseWarm) // or bonya.PauseCold
until, err := sandbox.Keepalive(ctx, 30*time.Minute) // also wakes a paused sandbox

snap, err := sandbox.CreateSnapshot(ctx, bonya.SnapshotOptions{Name: "baseline"})
restored, err := client.Create(ctx, bonya.CreateOptions{Snapshot: snap.ID})
snaps, err := sandbox.ListSnapshots(ctx)
err = client.DeleteSnapshot(ctx, snap.ID)

fork, err := sandbox.Fork(ctx, bonya.ForkOptions{Count: 2})
for _, child := range fork.Sandboxes {
	fmt.Println(child.ID, child.State)
}
```

A sandbox paused explicitly is not woken by exec or preview traffic; wake it with `Keepalive`. Snapshot `Name` is required (at most 128 characters).

## Jobs

```go
run, err := client.RunJob(ctx, bonya.JobSpec{
	NewSandbox:            &bonya.JobNewSandbox{},
	Cmd:                   []string{"./run-tests.sh"},
	CommandTimeoutSeconds: 600,
})
fmt.Println(run.Status, run.Result.ExitCode)
```

`RunJob` waits for the result; `StartJob` returns a run id immediately. Use `GetJobRun`, `ListJobRuns` / `ListAllJobRuns` and `CancelJobRun` to track runs.

### Schedules

```go
schedule, err := client.CreateJobSchedule(ctx, bonya.JobScheduleSpec{
	CronExpressions: []string{"0 3 * * *"},
	TimeZone:        "UTC",
	Job: bonya.JobSpec{
		NewSandbox: &bonya.JobNewSandbox{},
		Cmd:        []string{"./nightly.sh"},
	},
})

_, err = client.SetJobSchedulePaused(ctx, schedule.ID, true, "maintenance")
err = client.TriggerJobSchedule(ctx, schedule.ID)
err = client.DeleteJobSchedule(ctx, schedule.ID)
```

A schedule uses exactly one of `CronExpressions`, `IntervalSeconds` or `RunAt`.

## Organizations

```go
orgs, err := client.ListOrganizations(ctx)
client, err = bonya.NewClient(bonya.WithOrganizationID(orgs[0].ID))
```

The precedence is the option, then `BONYA_ORGANIZATION_ID`, then your personal organization.

## Errors

Every failure is an `*bonya.Error` with a `Kind`, the service's stable `Code`, a `Message`, and the `SandboxID` and `RetryAfter` where they apply. Match on kind with `errors.Is`:

```go
_, err := client.Get(ctx, "sb-missing")
switch {
case errors.Is(err, bonya.ErrNotFound):
	fmt.Println("gone")
case errors.Is(err, bonya.ErrRateLimited):
	var e *bonya.Error
	errors.As(err, &e)
	time.Sleep(e.RetryAfter)
}
```

| Kind | Meaning |
|---|---|
| `ErrInvalidRequest` | The request was malformed. |
| `ErrUnauthenticated` / `ErrPermissionDenied` | Bad credentials, or not allowed. |
| `ErrNotFound` | The resource doesn't exist. |
| `ErrConflict` | The resource is in a state that refuses the call. |
| `ErrSandboxPaused` | The sandbox is paused. Wake it with `Keepalive`. |
| `ErrSnapshotInUse` | The snapshot is still referenced. |
| `ErrLimitReached` / `ErrRateLimited` / `ErrNoCapacity` | A quota, rate limit or capacity limit. |
| `ErrTooLarge` | The payload exceeded a limit. |
| `ErrTimeout` | The call timed out. |
| `ErrUnavailable` | The service is unavailable. |
| `ErrOutcomeUnknown` | The result is unknown; retry with the same idempotency key. |
| `ErrInternal` | An unexpected server error. |

Server errors are RFC 9457 `problem+json`; see [Errors](/concepts/errors).
