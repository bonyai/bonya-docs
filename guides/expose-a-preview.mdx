---
title: Expose a preview
description: Publish a port from a sandbox at an HTTPS URL
---

Start something listening in a sandbox, publish its port, and open it in a browser. For the full model (auth modes, grants), see [Previews](/concepts/previews).

## 1. Start a server

Run it in a [session](/concepts/sessions) so it keeps running after you disconnect:

<CodeGroup>
```shell CLI
bonya session create web web-app -- python3 -m http.server 3000
```

```shell cURL
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/sessions" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "web-app", "command": ["python3", "-m", "http.server", "3000"]}'
```

```ts TypeScript
await sandbox.createSession("web-app", ["python3", "-m", "http.server", "3000"]);
```

```python Python
sandbox.create_session("web-app", ["python3", "-m", "http.server", "3000"])
```
</CodeGroup>

## 2. Publish the port

Ports must be 1024–65535.

<CodeGroup>
```shell CLI
bonya preview create web 3000
```

```shell cURL
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/previews" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"port": 3000}'
```

```ts TypeScript
const preview = await sandbox.createPreview(3000);
console.log(preview.url);
```

```python Python
preview = sandbox.create_preview(3000)
print(preview.url)
```

```go Go
preview, err := sandbox.CreatePreview(ctx, 3000, bonya.PreviewOptions{})
fmt.Println(preview.URL)
```
</CodeGroup>

The response has the preview `url` and, for a private preview, a one-time `grant`:

```json
{
  "id": "pv-cgl24jcazom7pdd4dzu5dsc2oe",
  "port": 3000,
  "auth": "private",
  "url": "https://pv-cgl24jcazom7pdd4dzu5dsc2oe.tv.bonya.ai",
  "grant": {
    "id": "pvg-mduwb73q6a5zogugmbeca3nrku",
    "expires_at": "2026-11-10T00:03:21Z",
    "token": "bpv_...",
    "exchange_url": "https://pv-....tv.bonya.ai/?bonya_token=bpv_..."
  }
}
```

## 3. Open it

A **private** preview (the default) is opened with the grant. Navigate once to `grant.exchange_url`; the gateway swaps the token for an `HttpOnly` cookie and redirects to the clean URL. The CLI prints this as `OPEN`, and the SDKs build it with `previewBrowserUrl` / `preview_browser_url`.

<Warning>
The `token` and `exchange_url` are shown only when the grant is created. Don't store them in a URL, log, or anywhere durable. If you lose one, create another grant.
</Warning>

A **public** preview needs no credential. Anyone with the URL can open it, so only choose it deliberately:

<CodeGroup>
```shell CLI
bonya preview create web 8080 --auth public
```

```shell cURL
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/previews" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"port": 8080, "auth": "public"}'
```
</CodeGroup>

## 4. Grants and cleanup

Mint, renew or revoke grants on a private preview without recreating it:

```shell
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/previews/$PREVIEW_ID/grants" \
  -H "Authorization: Bearer $BONYA_API_KEY" -H "Content-Type: application/json" \
  -d '{"ttl_seconds": 600}'
```

List and delete previews with `bonya preview list|delete`, `GET .../previews`, and `DELETE .../previews/{preview_id}`. Deleting a preview ends access immediately.
