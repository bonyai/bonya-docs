---
title: Snapshot a sandbox
description: Capture a running sandbox's disk state 
---

A snapshot captures a sandbox's disk state at a point in time. It's identified by its own `snapshot_id`, tied back to the `source_sandbox_id` it was taken from — but its identity outlives that source: you can delete the sandbox that produced a snapshot and keep the snapshot. See [Snapshots](/concepts/snapshots) for the full concept.

<Note>
To start a new sandbox from a snapshot, pass its id to create (`snapshot` in the SDKs and API, `snapshot` on the MCP `sandbox_create` tool). To clone a running sandbox directly, use fork.
</Note>

## Create a snapshot

The source sandbox must be **running** — paused, failed, or already-deleted sandboxes are rejected rather than snapshotted.

<CodeGroup>
```shell CLI
bonya snapshot create web
```

```python Python
snapshot = sandbox.snapshot(name="baseline", idempotency_key="snapshot-job-123")
print(snapshot.id, snapshot.source_sandbox_id)
```

```ts TypeScript
const snapshot = await sandbox.snapshot({ name: "baseline", idempotencyKey: "snapshot-job-123" });
console.log(snapshot.id, snapshot.sourceSandboxId);
```

```go Go
snapshot, err := sandbox.CreateSnapshot(ctx, bonya.SnapshotOptions{
	Name:           "baseline",
	IdempotencyKey: "snapshot-job-123",
})
fmt.Println(snapshot.ID, snapshot.SandboxID)
```
</CodeGroup>

The SDKs accept (or auto-generate) an idempotency key for create, so a retried call returns the same snapshot identity rather than minting a second one. If the source sandbox isn't running, the call fails with a `lifecycle_conflict` error.

## Delete a snapshot

Delete is idempotent — calling it again on an already-deleted snapshot is a local no-op, not an error.

<CodeGroup>
```shell CLI
bonya snapshot delete web <snapshot-id>
```

```python Python
snapshot.delete()
snapshot.delete()  # no-op
```

```ts TypeScript
await snapshot.delete();
await snapshot.delete(); // no-op
```

```go Go
client.DeleteSnapshot(ctx, snapshot.ID)
```
</CodeGroup>

Because a snapshot's identity outlives its source sandbox, you can delete a snapshot's source sandbox first and its snapshot later — the two are independent decisions.
