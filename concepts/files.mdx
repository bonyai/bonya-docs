---
title: Files
description: Read, write, and manage files on a sandbox's filesystem
---

Every sandbox exposes a filesystem API under `/v1/sandbox/{sandbox_id}/fs`. All operations take a `sandbox_id` and, where they act on a path, a `path` query parameter.

<Note>
Read and write bodies are **raw bytes** (`application/octet-stream`) — not tar archives, not multipart form data. Each call moves exactly one file's contents.
</Note>

## Reading a file

```
GET /v1/sandbox/{sandbox_id}/fs/read
```

<ParamField query="path" type="string" required>
  Path to the file.
</ParamField>

Returns `200` with the raw file contents as `application/octet-stream`.

<CodeGroup>
```shell cURL
curl -s "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs/read?path=/root/hello.txt" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -o ./hello.downloaded.txt
```

```shell CLI
bonya fs read $SANDBOX_ID /root/hello.txt
```

```ts TypeScript
const payload = await sandbox.readFile("/root/hello.txt");
```

```python Python
payload = sandbox.read_file("/root/hello.txt")
```

```go Go
payload, err := sandbox.ReadFile(ctx, "/root/hello.txt", 0)
```
</CodeGroup>

**MCP:** `fs_read` returns the file's contents as a UTF-8 string, since MCP tool calls carry inline text rather than binary bytes.

## Writing a file

```
PUT /v1/sandbox/{sandbox_id}/fs/write
```

<ParamField query="path" type="string" required>
  Path to write to.
</ParamField>

The request body is the raw file contents (`application/octet-stream`). Returns `204` on success — no response body.

<CodeGroup>
```shell cURL
curl -s -X PUT "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs/write?path=/root/hello.txt" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @./hello.txt
```

```shell CLI
bonya fs write $SANDBOX_ID /root/hello.txt ./hello.txt
```

```ts TypeScript
await sandbox.writeFile("/root/hello.txt", "hello\n");
```

```python Python
sandbox.write_file("/root/hello.txt", "hello\n")
```

```go Go
sandbox.WriteFile(ctx, "/root/hello.txt", []byte("hello\n"))
```
</CodeGroup>

**MCP:** `fs_write` takes UTF-8 text `content` and creates or overwrites the file, returning `{ ok: true, path, bytes }`.

## Uploading and downloading a local file

There's no dedicated REST endpoint for upload/download — the CLI and SDKs implement it as a local file streamed through the same raw-bytes `fs/read` and `fs/write` endpoints above.

<CodeGroup>
```shell CLI
bonya fs upload $SANDBOX_ID ./hello.txt /root/hello.txt
bonya fs download $SANDBOX_ID /root/hello.txt ./hello.downloaded.txt
```

```ts TypeScript
await sandbox.uploadFile("./hello.txt", "/root/hello.txt");
await sandbox.downloadFile("/root/hello.txt", "./hello.downloaded.txt");
```

```python Python
sandbox.upload_file("./hello.txt", "/root/hello.txt")
sandbox.download_file("/root/hello.txt", "./hello.downloaded.txt")
```

```go Go
sandbox.Upload(ctx, "./hello.txt", "/root/hello.txt")
sandbox.Download(ctx, "/root/hello.txt", "./hello.downloaded.txt")
```
</CodeGroup>

**MCP:** there's no `fs` upload/download tool — MCP tool calls carry inline UTF-8 text, not binary file transfers, so `fs_read`/`fs_write` are the only way to move file contents through MCP.

## Listing a directory

```
GET /v1/sandbox/{sandbox_id}/fs/list
```

<ParamField query="path" type="string" required>
  Directory path to list.
</ParamField>

Returns `{ "files": [ ...file ] }`.

<CodeGroup>
```shell cURL
curl -s "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs/list?path=/root" \
  -H "Authorization: Bearer $BONYA_API_KEY"
```

```shell CLI
bonya fs ls $SANDBOX_ID /root
```

```ts TypeScript
const entries = await sandbox.listFiles("/root");
```

```python Python
entries = sandbox.list_files("/root")
```

```go Go
entries, err := sandbox.ListDir(ctx, "/root")
```
</CodeGroup>

**MCP:** `fs_list` returns `{ files: [{ path, name, kind, size, mode, modified_at_unix_nanos }, ...] }`.

## Getting file metadata

```
GET /v1/sandbox/{sandbox_id}/fs/stat
```

<ParamField query="path" type="string" required>
  Path to stat.
</ParamField>

Returns `{ "file": { ...file } }`.

<CodeGroup>
```shell cURL
curl -s "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs/stat?path=/root/hello.txt" \
  -H "Authorization: Bearer $BONYA_API_KEY"
```

```shell CLI
bonya fs stat $SANDBOX_ID /root/hello.txt
```

```ts TypeScript
const info = await sandbox.statFile("/root/hello.txt");
console.log(info.kind, info.size);
```

```python Python
info = sandbox.stat_file("/root/hello.txt")
print(info.kind, info.size)
```

```go Go
info, err := sandbox.Stat(ctx, "/root/hello.txt")
fmt.Println(info.Kind, info.Size)
```
</CodeGroup>

**MCP:** `fs_stat` returns `{ file: { path, name, kind, size, mode, modified_at_unix_nanos } }`.

### File fields

<ResponseField name="path" type="string" required>
  Full path.
</ResponseField>
<ResponseField name="name" type="string" required>
  Base name.
</ResponseField>
<ResponseField name="kind" type="string" required>
  One of `file`, `directory`, `symlink`, `other`.
</ResponseField>
<ResponseField name="size" type="integer" required>
  Size in bytes.
</ResponseField>
<ResponseField name="mode" type="integer" required>
  Permission bits as reported by the guest, 0–4095.
</ResponseField>
<ResponseField name="modified_at_unix_nanos" type="integer" required>
  Last-modified time.
</ResponseField>

## Creating a directory

```
POST /v1/sandbox/{sandbox_id}/fs/mkdir
```

Request body:

<ParamField body="path" type="string" required>
  Directory path to create.
</ParamField>

Returns `201` on success.

<CodeGroup>
```shell cURL
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs/mkdir" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"path": "/root/output"}'
```

```shell CLI
bonya fs mkdir $SANDBOX_ID /root/output
```

```ts TypeScript
await sandbox.mkdirFile("/root/output");
```

```python Python
sandbox.mkdir_file("/root/output")
```

```go Go
sandbox.Mkdir(ctx, "/root/output")
```
</CodeGroup>

**MCP:** `fs_mkdir` creates the directory (and any missing parents), returning `{ ok: true, path }`.

## Renaming or moving

```
POST /v1/sandbox/{sandbox_id}/fs/rename
```

Request body:

<ParamField body="from" type="string" required>
  Source path.
</ParamField>
<ParamField body="to" type="string" required>
  Destination path.
</ParamField>

Returns `200` on success.

<CodeGroup>
```shell cURL
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs/rename" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"from": "/root/hello.txt", "to": "/root/output/hello.txt"}'
```

```shell CLI
bonya fs mv $SANDBOX_ID /root/hello.txt /root/output/hello.txt
```

```ts TypeScript
await sandbox.moveFile("/root/hello.txt", "/root/output/hello.txt");
```

```python Python
sandbox.move_file("/root/hello.txt", "/root/output/hello.txt")
```

```go Go
sandbox.Rename(ctx, "/root/hello.txt", "/root/output/hello.txt")
```
</CodeGroup>

**MCP:** `fs_rename` covers this, returning `{ ok: true, from, to }`.

## Deleting

```
DELETE /v1/sandbox/{sandbox_id}/fs
```

<ParamField query="path" type="string" required>
  Path to remove.
</ParamField>
<ParamField query="recursive" type="boolean" default="false">
  Whether to remove a non-empty directory recursively.
</ParamField>

Returns `204` on success.

<CodeGroup>
```shell cURL
curl -s -X DELETE "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/fs?path=/root/output&recursive=true" \
  -H "Authorization: Bearer $BONYA_API_KEY"
```

```shell CLI
bonya fs rm $SANDBOX_ID /root/output --recursive
```

```ts TypeScript
await sandbox.removeFile("/root/output", true);
```

```python Python
sandbox.remove_file("/root/output", recursive=True)
```

```go Go
sandbox.RemoveAll(ctx, "/root/output")
```
</CodeGroup>

**MCP:** `fs_delete` covers this — pass `recursive: true` to delete a non-empty directory. Returns `{ ok: true, deleted: path }`.
