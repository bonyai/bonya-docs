A **preview** exposes a port inside a sandbox as an HTTPS URL, so you can view a dev server, API, or any other listener from a browser.

## Creating a preview

<CodeGroup>
```shell cURL
curl -s -X POST "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/previews" \
  -H "Authorization: Bearer $BONYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"port": 3000}'
```

```shell CLI
bonya preview create web 3000
```

```ts TypeScript
const preview = await sandbox.createPreview(3000);
console.log(preview.url);
```

```python Python
preview = sandbox.create_preview(3000)
print(preview.url)
```

```go Go
preview, err := sandbox.CreatePreview(ctx, 3000, bonya.PreviewOptions{})
fmt.Println(preview.URL)
```
</CodeGroup>

**MCP:** `preview_create`.

Request body:

<ParamField body="port" type="integer" required>
  Port to expose, 1024–65535. Privileged ports are never previewable.
</ParamField>
<ParamField body="auth" type="string" default="private">
  `private` or `public` (see below).
</ParamField>
<ParamField body="ttl_seconds" type="integer">
  Lifetime of the first grant on a private preview.
</ParamField>

Create also accepts an `Idempotency-Key` header. See [Idempotency](/concepts/idempotency).

Returns `201` with the preview:

```json
{
  "id": "pv-cgl24jcazom7pdd4dzu5dsc2oe",
  "sandbox_id": "sb-rcn9pz5ej2rnhi",
  "port": 3000,
  "auth": "private",
  "url": "https://pv-cgl24jcazom7pdd4dzu5dsc2oe.tv.bonya.ai",
  "created_by_user_id": "usr-f5q6bpaml50q81",
  "created_at": "2026-11-09T23:03:21.471086Z",
  "grant": {
    "id": "pvg-mduwb73q6a5zogugmbeca3nrku",
    "expires_at": "2026-11-10T00:03:21.471086Z",
    "token": "bpv_...",
    "exchange_url": "https://pv-....tv.bonya.ai/?bonya_token=bpv_..."
  }
}
```

<Warning>
The grant's `token` and `exchange_url` are returned **only** by the call that creates the grant. List and get never include them, and they can't be retrieved again. Anyone holding them can open the preview, so treat them as secrets. If you lose one, create a new grant.
</Warning>

## Auth modes

- **`private`** (default) — only holders of a *grant* can open the preview. Members of your organization are not let in automatically.
- **`public`** — anyone with the URL can open it, with no credential at all. Public is only ever explicit: omitting `auth` never yields a public URL.

### Opening a private preview

Navigate once to the grant's `exchange_url`. The preview gateway validates the token, swaps it for a host-scoped `HttpOnly` cookie, and redirects to the same address without the token. Open it once and let the cookie carry the session. Don't share the URL.

The SDKs expose `previewBrowserUrl` / `preview_browser_url`, which builds this URL from a preview and its grant. The CLI prints it as `OPEN` when you run `bonya preview create`.

## Grants

A grant is a time-limited credential for a private preview. Manage grants under `/v1/sandbox/{sandbox_id}/previews/{preview_id}/grants`:

| Operation | Endpoint | SDK | MCP |
| --- | --- | --- | --- |
| Create | `POST .../grants` with `{ "ttl_seconds": 600 }` | `createPreviewGrant` | `preview_grant_create` |
| List | `GET .../grants` | `listPreviewGrants` | `preview_grant_list` |
| Renew | `POST .../grants/{grant_id}/renew` | `renewPreviewGrant` | `preview_grant_renew` |
| Revoke | `POST .../grants/{grant_id}/revoke` | `revokePreviewGrant` | `preview_grant_revoke` |

## Listing and getting

`GET /v1/sandbox/{sandbox_id}/previews` returns `{ "previews": [...] }`, and `GET .../previews/{preview_id}` returns one. **MCP:** `preview_list`, `preview_get`.

## Deleting a preview

<CodeGroup>
```shell cURL
curl -s -X DELETE "https://api.bonya.ai/v1/sandbox/$SANDBOX_ID/previews/$PREVIEW_ID" \
  -H "Authorization: Bearer $BONYA_API_KEY"
```

```shell CLI
bonya preview delete web $PREVIEW_ID
```

```ts TypeScript
await sandbox.deletePreview(preview.id);
```

```python Python
sandbox.delete_preview(preview.id)
```

```go Go
err = sandbox.DeletePreview(ctx, preview.ID)
```
</CodeGroup>

Delete returns `200` with the preview, which now has a `deleted_at`. **MCP:** `preview_delete`.
